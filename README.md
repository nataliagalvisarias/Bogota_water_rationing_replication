# Bogotá water-rationing replication package

Replication materials for **“Does Scheduled Urban Water Rationing Increase Reported Domestic Violence? Evidence from Bogotá’s Rotating Rationing Policy.”**

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22681258.svg)](https://doi.org/10.5281/zenodo.22681258)
[![Repository](https://img.shields.io/badge/GitHub-replication-181717?logo=github)](https://github.com/nataliagalvisarias/Bogota_water_rationing_replication)

## Executive summary

The paper studies Bogotá’s April 2024–May 2025 rotating water-rationing programme. The municipal network assigned twelve fixed hydraulic service polygons to nine shifts and suspended each shift on a published rotation. The primary estimand is the intention-to-treat effect of assignment to the announced non-price rationing policy on counts of reported domestic violence.

The design compares 50-metre cells on opposite sides of sixteen shared hydraulic boundaries. The primary specification uses the operational 08:00–08:00 suspension clock, cell fixed effects, and boundary-by-date fixed effects. Identification therefore comes from within-cell changes in scheduled treatment as the rotation advances, while the boundary-by-date effects absorb shocks common to each local comparison. A 63-analysis-day moving-block bootstrap is the primary inference procedure; nine-day rotation-cycle clustering is reported as a complement.

The primary estimate is −0.0081 reports per identifying cell-day. Its 63-day block-bootstrap 95% interval is [−0.0298, 0.0086], or [−13.9%, 4.0%] of the control-side mean. The evidence therefore does not indicate that Bogotá’s scheduled rationing policy increased reported domestic violence. This is a policy-assignment ITT, not an estimate of household-level realised water deprivation.

## Data availability and licensing

### Restricted outcome data

The outcome data are incident-level domestic-violence reports from Bogotá’s C4 / Línea 123 Emergency Response Center, held by the *Secretaría Distrital de Seguridad, Convivencia y Justicia*. The author is permitted to analyse these administrative records but not to redistribute the raw extract. No raw record, coordinate, or case identifier is included in this repository.

Researchers seeking an identical extract should submit a public-information request to the Secretariat through Bogotá’s official petition system, *Bogotá te escucha*. The request should specify January 2023–May 2025 Línea 123 incidents classified as violence against women and request the incident timestamp, classification, and georeferenced location. See [`docs/DATA_ACCESS.md`](docs/DATA_ACCESS.md) for the field specification and restricted rebuild configuration.

### Public policy and spatial inputs

- The rationing schedule is transcribed from EAAB Resolución 291 de 2024 and Resolución 980 de 2024.
- The hydraulic service polygons are from the *Empresa de Acueducto y Alcantarillado de Bogotá* (EAAB); the supplied GeoPackage uses EPSG:3116.
- `polygon_shift_crosswalk.csv` records the mapping from service polygons to the nine published shifts.

These files are in `data/public/`. They remain subject to the terms of their original public-sector publishers.

### Curated replication files

`data/derived/` contains balanced count panels at boundary × polygon-side × 50-metre distance band × analysis-date resolution, along with exposure areas, pinned bandwidths, and along-boundary segment panels. These aggregates contain no coordinates or identifiers and are sufficient to reproduce every statistical result, generated figure, and table in the manuscript. They are released under CC BY 4.0; code is released under the MIT License. See [`LICENSE`](LICENSE) and [`CODEBOOK.md`](CODEBOOK.md).

## Software and system requirements

The public replication was verified with:

- R 4.3.1; R 4.1 or newer is required.
- `dplyr` 1.1.4, `readr` 2.1.5, `tidyr` 1.3.1, `sf` 1.0-20, `ggplot2` 3.5.1, `fixest` 0.12.1, and `tibble` 3.2.1.
- `lwgeom` 0.2-14 is needed only for the optional restricted-data segment rebuild.
- GDAL 3.8.5, GEOS 3.13.0, and PROJ 9.5.1 for spatial operations.
- Python 3.13.12 was present in the verification environment but is not called by the active pipeline.
- Optional manuscript compilation: pdfTeX 1.40.25 / TeX Live 2023 with `booktabs`, `threeparttable`, `float`, `multirow`, `geometry`, `setspace`, `natbib`, `hyperref`, and `footmisc`.

`rdrobust` is **not required or called**. The MSE-optimal bandwidths used by the frozen specification are shipped in `data/derived/bandwidths_mserd.csv`; estimators are implemented directly in R. This prevents package-version changes from silently selecting different bandwidths.

The aggregate-only public run takes approximately 40 seconds on the verified Apple-silicon system and uses less than 4 GB of memory. The restricted rebuild is slower because it recomputes point-to-boundary distances and segment assignments. Exact versions and platform details appear in [`docs/session_info.txt`](docs/session_info.txt).

Install the required public-path packages with:

```bash
Rscript -e 'install.packages(c("dplyr", "readr", "tidyr", "sf", "ggplot2", "fixest", "tibble"))'
```

## Replication instructions

### 1. Clone and enter the repository

```bash
git clone https://github.com/nataliagalvisarias/Bogota_water_rationing_replication.git
cd Bogota_water_rationing_replication
```

### 2. Verify the archived files

On macOS:

```bash
md5 -r $(find . -type f -not -path './.git/*' -not -path './docs/checksums.md5' | sort) > /tmp/current.md5
diff -u docs/checksums.md5 /tmp/current.md5
```

On GNU/Linux:

```bash
find . -type f -not -path './.git/*' -not -path './docs/checksums.md5' -print0 \
  | sort -z | xargs -0 md5sum > /tmp/current.md5
diff -u docs/checksums.md5 /tmp/current.md5
```

### 3. Run the complete public pipeline

From the repository root:

```bash
Rscript code/00_master.R
```

The master script validates the sixteen-boundary adjacency set, reruns the spatial and label-placebo exercises, estimates the primary operational and secondary calendar clocks, performs the moving-block bootstrap and rotation-cycle clustering, estimates dynamics, the common 500-metre bandwidth, 500/1,000-metre segments and PPML, regenerates Tables 1–4, B1 and C1 and Figures 3–8, and audits 22 frozen manuscript displays against the output CSVs.

A successful run ends with:

```text
[08] all 22 frozen displays found byte-for-byte in submission/main.tex
Replication complete.
```

### 4. Compile the manuscript (optional)

```bash
cd submission
latexmk -pdf -interaction=nonstopmode -halt-on-error -outdir=../output/pdf main.tex
latexmk -pdf -interaction=nonstopmode -halt-on-error -outdir=../output/pdf title_page.tex
cd ..
```

### 5. Optional restricted-data rebuild

Authorised users can rebuild the curated panels by supplying paths at run time. No personal path is embedded in the repository.

```bash
INPUT_ROOT="/absolute/path/to/project/data" \
INCIDENTS_ALL="/absolute/path/to/project/data/raw/NUSE_NGA.dsv" \
Rscript code/00_master.R --full
```

All outputs remain inside the repository. The master script stops if only one variable is supplied or if either path is invalid.

## Superseded artifacts

The current panels were rebuilt after an audit showed that an earlier nearest-active-boundary assignment rule made boundary membership depend on the rotating treatment. The final design assigns reports to every qualifying boundary using fixed geography, completes the usable cell-date grid with zeros, uses all sixteen validated boundaries, and treats schedule-label permutations as placebo checks rather than exact randomization inference.

Historical scripts and estimates are not called by the active pipeline and are not mixed with current outputs. [`superseded/README.md`](superseded/README.md) explains the changes; [`superseded/artifact_log.csv`](superseded/artifact_log.csv) records the disposition of the former script families and claims.
